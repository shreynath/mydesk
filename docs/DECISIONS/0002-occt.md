# ADR 0002: Geometry kernel — OCCT (planned)

## Status

Proposed / deferred until Phase 2

## Context

Mechanical and interchange (STEP/IGES) need a B-rep kernel. Writing one from scratch is multi-year and error-prone.

## Decision

Evaluate **Open CASCADE Technology** behind a MyDesk `GeometryKernel` interface. Draft MVP continues with lightweight analytic 2D entities and does not link OCCT yet.

## Consequences

- Keep `core/geometry` free of OCCT types in public Draft APIs for now.
- When adopted: pin version, document LGPL linking obligations, add STEP fixtures.
- Boolean failures and tolerance must surface as user-visible diagnostics — never silent corruption.
