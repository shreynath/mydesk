# ADR 0003: Qt 6 Widgets desktop UI

## Status

Accepted (2026-10-10)

## Context

Professional CAD UIs need dense docking, menus, and native desktop integration. Engine must remain headless-testable.

## Decision

Use **Qt 6 Widgets** for `apps/desktop`. All document mutations go through `mydesk::commands::Session`. Core libraries must not depend on Qt.

## Consequences

- LGPL/commercial Qt licensing obligations documented in THIRD_PARTY.
- CI installs Qt per OS; headless preset builds tests without UI.
- Future QML allowed for selected experiences only.
