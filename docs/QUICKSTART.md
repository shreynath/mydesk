# Quick start — MyDesk Draft

1. Build (`docs/BUILD.md`).
2. Launch **MyDesk Draft** (`MyDeskDraft`).
3. Draw a line: type `L`, click two points, or `L 0,0 100,50`.
4. Draw a circle: `C 40,25 15`.
5. Layers: `LAYER NEW Walls`, `LA MAKE Doors`, `LAYER OFF Walls`, `LAYER ?`.
6. Select with click or window/crossing; `E` erases; `U` undoes.
7. File → Save → `Drawing1.mydesk`. Optional: Export DXF (partial).

Pan: middle-mouse. Zoom: scroll. Fit: View → Fit.
