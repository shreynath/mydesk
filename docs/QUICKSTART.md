# Quick start — MyDesk Draft

1. Build (`docs/BUILD.md`).
2. Launch **MyDesk**.
3. Draw a line: type `L`, click two points (snaps show as green squares), or `L 0,0 100,50`.
4. Draw a circle: `C`, click center, enter radius or click a rim point; or `C 40,25 15`.
5. Select with a click; `E` erases selection; `U` undoes.
6. File → Save → `Drawing1.mydesk`. Re-open to verify round-trip.
7. Optional: File → Export DXF (LINE/CIRCLE only; partial).

Pan: middle-mouse or Shift+drag. Zoom: scroll wheel. Fit: View → Fit.
