MyDesk Studio 0.3.0

Standalone modifier-stack 3D modeling application.

This package contains only the MyDesk Studio application and
its product documentation. It is not a suite launcher and does not install any
other MyDesk product.

Package status
--------------
This is an unsigned development package produced by CPack. Third-party runtime
libraries are not bundled yet. It must not be described as a notarized,
redistributable, or production installer until the platform release gates in
docs/PACKAGING.md have passed.
